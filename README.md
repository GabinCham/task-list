# Listes

Application Expo Todo avec **4 onglets personnalisables**, **3 sections par onglet**, et persistance via **AsyncStorage**.

## Fonctionnalités

- 4 onglets (Perso, Travail, Courses, Idées) : nom et icône modifiables
- 3 sections par onglet : titre renommable (appui long)
- Ajout / coche / suppression de tâches
- Sauvegarde automatique dans AsyncStorage
- Bouton Reset pour revenir aux listes par défaut

## Démarrage

```bash
npm install
npx expo start
```

Puis ouvrir sur Expo Go (iOS/Android) ou le web.
